<objective>
## Goal
Everything 07-01 gave the CLI, in the GUI: choose a YubiKey slot when unlocking or creating a vault, add/change/remove it in Change master key, give the other copy's slot in Merge, see "Touch your YubiKey…" while the key waits, and have the slot remembered for that vault next time.

## Purpose
Without this, YubiKey vaults are CLI-only; most daily use is the GUI.

## Output
- `YubiKeyField` widget (No YubiKey / Slot 1 / Slot 2) used by the unlock screen, Change master key and Merge
- A touch-prompt hook in pwvault.py the GUI points at its status text
- Remembered slot per vault path in settings.ini (no secrets), with settings writes that keep other sections
- tests/test_gui_yubikey.py (emulated key), README and CHANGELOG lines
</objective>

<acceptance_criteria>

## AC-1: Unlock and create with a YubiKey
```gherkin
Given a YubiKey-protected vault and the emulated key
When I enter the password, choose "YubiKey slot 2" and press Unlock
Then the vault opens; with "No YubiKey" it shows "Wrong master password or key file."
When I create a new vault with a slot chosen
Then it opens only with that slot (and the help text says a YubiKey also counts as a strong factor)
```

## AC-2: Remembered slot, no secrets stored
```gherkin
Given I unlocked a vault with slot 2
When the unlock screen shows for that vault again (lock, restart)
Then slot 2 is preselected; another vault path starts at "No YubiKey"
And settings.ini holds only the vault path and slot number, and saving the theme keeps it (and vice versa)
```

## AC-3: Change master key and Merge
```gherkin
Given an open vault
When Change master key sets "YubiKey slot 2" (or "No YubiKey")
Then the vault opens only with the new choice, and the remembered slot follows
And the "current password" check uses the vault's current YubiKey
When Merge has "Same password…" unticked and a slot chosen for the other copy
Then it opens the other copy with that slot
```

## AC-4: Touch prompt and errors
```gherkin
Given a slot that needs a touch
When the key starts waiting
Then the unlock screen (or dialog) shows "Touch your YubiKey…" before the wait ends
Given no key, missing extra, slot not set up, timeout or several keys
Then the message from 07-01 appears inline, the password field is cleared as for a wrong password, and nothing is written
```

## AC-5: Look and feel (human checkpoint)
```gherkin
Given the GUI on this desktop (no YubiKey needed)
Then the YubiKey choice sits under Key file on the unlock screen, Change master key and Merge, in both themes
And choosing a slot with no key plugged in shows the "No YubiKey found" message
```
