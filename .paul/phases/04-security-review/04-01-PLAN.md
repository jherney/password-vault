<objective>
## Goal
Audit every v1.3 change for security problems, record each finding with its severity and location, and stop the test suite from writing a key file into the repository.

## Purpose
Core value: one encrypted vault I control. v1.3 added backups, TOTP secrets and a settings file. Phase 4 exists to find weaknesses in those before release. This plan only finds and records them. Fixes come in a later plan, once the findings are known and the user has chosen what to fix.

## Output
- `.paul/phases/04-security-review/04-01-FINDINGS.md`: one row per finding (id, severity, file:line, description, status)
- `tests/`: the test that wrote `pwvault.keyx` into the repo root now uses a temporary directory
</objective>
