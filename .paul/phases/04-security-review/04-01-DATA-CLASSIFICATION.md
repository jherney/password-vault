# pwvault data classification, v1.3

**Plan:** 04-01 · **Date:** 2026-10-30 · **Covers:** data pwvault collects, stores, shows, and deletes, as of commit `28c091c`.
**Scope:** data handled by the code and the repository. Not legal compliance; no regulatory conclusion is drawn.

## Classes

| Class | Meaning |
|-------|---------|
| **Restricted** | Credentials and key material. Disclosure lets someone log in or open the vault. |
| **Confidential** | Account identifiers and notes. Disclosure reveals which accounts the user has. |
| **Internal** | Settings and project metadata. No personal or credential value. |
| **Public** | Source code, documentation, and the test vectors from RFC 6238. |

## Trace of the restricted data flows

1. **Entry to disk:** user input → `Vault.save` → KDBX encryption → `_write` (lock, check, backup, atomic write) → vault file. Each stage is in `pwvault.py`.
2. **Vault to screen or clipboard:** unlock → `Vault.open` → entry fields. Show and copy are explicit actions. The clipboard clears itself.
3. **Vault to exports:** `export` writes plaintext. The warning is printed. This is the one path where restricted data leaves encryption by design.
4. **Backups:** created before every save; restored only with a key check; purged after a master-key change (F-01 fixed: the purge finishes even after a crash).
5. **Logs:** pwvault writes no log files. Stdout carries only what the user asked to see.

## Findings linked to data handling

- F-01 (fixed): old-key backups could survive a crash during a master-key change.
- F-02, F-03: explicit commands print secrets or codes. Accepted.
- F-06: clipboard handling. Accepted.
- F-09: a key file could be saved into a git folder. `*.keyx` is now ignored.
- F-11, F-12: CI and dependency pinning. Deferred to Phase 5.

## Retention summary

| Data | Retention |
|------|-----------|
| Backups | Newest 10 per vault. All removed after a master-key change. |
| Clipboard | Cleared after 20 s, if unchanged. |
| Unlocked session | Locked after 5 minutes idle; an open edit dialog holds it for up to 10 more minutes. |
| Recycle bin | Kept until emptied. |
| CSV imports and exports | Kept until the user deletes them. |
