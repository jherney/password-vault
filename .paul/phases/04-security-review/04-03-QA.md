## Defects

| ID | Area | Severity | Defect | Status |
|----|------|----------|--------|--------|
| CLI-01 | export | medium (data loss) | `export` overwrote an existing file without asking; a user's own notes file was replaced | **Fixed**: refuses an existing path, like `keyfile` and `init`. Test: `test_export_never_overwrites_an_existing_file` |
| CLI-02 | add | low | `add` with blank title and URL saved an untitled entry; `list` showed a blank row and messages showed 'None'. The GUI already refused this | **Fixed**: refuses with "an entry needs a title or a URL". Test: `test_add_refuses_an_entry_with_no_title_or_url` |
| GUI-01 | quit | low | Closing the window with the idle-lock or clipboard timer pending left it scheduled; it fired into the destroyed interpreter ("invalid command name auto_lock" in the test output) | **Fixed**: `quit()` cancels both timers. Test: `test_quit_cancels_pending_lock_and_clipboard_timers` |
| CLI-03 | trash restore | low (usability) | Restore always put the entry in Root, not the group it came from. Entries were not lost | **Fixed** (follow-up): trashing records the group in the standard `PreviousParentGroup` element, which KeePassXC also writes; restore returns there, else to Root. Tests: `test_trash_restore_returns_entry_to_its_original_group`, `test_trash_restore_falls_back_to_root_when_group_is_gone`. Checked with keepassxc-cli 2.8.0: the trashed entry reads correctly |
| CLI-04 | export | low | `export` into a missing directory creates that directory (mode 0700) and writes the file | **Accepted**: intentional in `write_private`; the file itself is private |
| CLI-05 | import | low | Importing a non-CSV file prints its first line as "columns found", which can be a long line | **Accepted**: the header line of a file the user chose; no secret is printed for a valid export. Shortening it is cosmetic |

- Baseline before the fixes: full suite exit 0, 151 tests (per 04-01 summary).
- After the fixes: full suite 154 tests OK, exit 0 (151 baseline + 3 regression tests).
