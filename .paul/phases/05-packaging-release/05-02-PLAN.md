<objective>
## Goal
`pwvault-gui --install-launcher` adds pwvault to the desktop app menu for the current user, and `--uninstall-launcher` removes it. No root needed.

## Purpose
ROADMAP Phase 5 requires the GUI in the desktop app menu. A per-user install avoids needing root and avoids packaging data files (setuptools `py-modules` only ships modules).

## Output
- `install_launcher()` / `uninstall_launcher()` in pwvault_gui.py, with the SVG icon embedded as a string
- `~/.local/share/applications/pwvault.desktop` and `~/.local/share/icons/hicolor/scalable/apps/pwvault.svg` written on install
- tests/test_desktop_launcher.py
</objective>

<acceptance_criteria>

## AC-1: Install writes a valid desktop entry and icon
```gherkin
Given a home directory with no pwvault launcher
When `pwvault-gui --install-launcher` runs
Then pwvault.desktop exists with Type=Application, Name=pwvault, Icon=pwvault, Categories containing Utility and Security, and Exec pointing at the pwvault-gui executable; the SVG icon exists in the hicolor scalable apps directory
```

## AC-2: Install is repeatable and never touches other files
```gherkin
Given a launcher is already installed
When --install-launcher runs again
Then the two files are replaced with identical content and no other file in those directories changes
```

## AC-3: Uninstall removes only pwvault's files
```gherkin
Given the launcher is installed
When `pwvault-gui --uninstall-launcher` runs
Then pwvault.desktop and the icon are removed; when they are already absent, it reports nothing to remove and exits 0
```

## AC-4: The Exec path works from the desktop
```gherkin
Given the desktop environment's minimal PATH
When the Exec line is run
Then it names an absolute path to pwvault-gui when one is found, else the bare name
```

    - Add `install_launcher(home=None, exec_path=None) -> list[Path]`: write the icon with `pwvault.write_private`-style atomic write (mode 0644 is fine for an icon; use plain write via a temp file and os.replace), and the .desktop file with the same method.
